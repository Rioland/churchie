# Roadmap

Churchie is built in stages so each one is usable and reviewable on its own.

## ✅ Phase 1 — Presentation core (v0.1)

- Schedule / Preview / Live workflow, projector output, Black / Clear / Logo
- Song library, editor, search, `.txt` and OpenLyrics import
- KJV built in, reference parser, Zefania XML Bibles
- Picture backgrounds and themes, live theme editing
- Autosave, schedule files, keyboard and clicker control
- Cross-platform builds on GitHub Actions, Codespaces dev environment

## Phase 2 — Motion and media

- Video and motion backgrounds (LibVLCSharp), looping
- Play video items in the schedule with transport controls
- Slide transitions (fade/cut) on the projector
- Per-song theme override

## Phase 3 — Bringing churches over

- Import from EasyWorship 6/7 (`Songs.db`), OpenLP and ProPresenter exports
- PowerPoint / PDF presentations as schedule items (rendered to images)
- Song arrangement (V1 C V2 C B C) without duplicating text
- Multiple Bibles side by side (e.g. English + Yoruba on one slide)

## Phase 4 — Beyond one screen

- Stage display / confidence monitor for the worship team (current + next slide, clock)
- Lower-thirds output for livestreams (transparent background)
- NDI output
- Phone remote: a small web page served by Churchie to change slides from any phone on the church Wi-Fi

## Phase 5 — Video mixing (vMix-style)

- Built on libobs: camera inputs, scenes, picture-in-picture
- Lyrics and scripture as overlays on camera feeds
- Recording and streaming to YouTube / Facebook

Ideas and priorities can change — open an issue for anything your church needs first.
